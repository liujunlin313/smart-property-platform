# 栖云物业 UI 设计说明

## 产品对象与主路径

- 系统管理员：跨小区资产、人员、收费、通知、挂牌和统计工作。
- 物业工作人员：在后端授权小区范围内处理资产、住户、账单与服务事项。
- 居民：查看自己的居所、产权、账单与通知，并可上报服务事项。

管理端以“物业工作台”为首入口，随后按资产、居民服务、费用、运营与统计分组；居民端以顶栏快捷入口完成个人事务。

## 视觉系统

- 品牌色：深青绿导航 + 青绿色操作强调；白色业务卡与浅灰背景承载信息。
- 语义色：绿色表示已完成/正常，橙色表示待处理/注意，红色表示逾期/紧急，蓝色表示进行中。
- 字体：中文系统字体优先，避免装饰性英文标题占据页面空间。
- 密度：筛选、表格与详情以操作效率为准；统计卡只保留有明确下一步的关键指标。

## 组件约定

- `PageHeader`：页面标题、业务说明与主操作。
- `SectionCard`：同一业务区块的标题、描述和内容容器。
- `StatCard`：可行动的概览指标，不用于重复堆叠。
- `StatusTag`：状态码的统一中文和颜色表达。
- `EmptyState`：无数据时说明原因和下一步，而非仅显示空白。

## 响应式规则

- 宽屏：保留左侧分组导航与表格多列信息。
- 中屏：侧栏收窄为图标导航，筛选区域自动换列。
- 窄屏：导航转为横向图标入口，表单和指标改为单列，Drawer 宽度受视窗约束。

## 不变的系统边界

UI 只表达已经存在的后端数据与权限结果；不在浏览器中扩大 `PROPERTY_STAFF` 的范围，不为居民端增加可控身份参数，不以硬编码统计或假数据替代接口结果。
